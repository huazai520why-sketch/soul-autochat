# 她的性格建模（analyze_her）

## 六维（每项必须落到具体行为，不用形容词）
1. **核心法则 3 条**：当[场景]→她会[行为]，而不是[易误判成的行为]
2. **表达风格**：口头禅 / 表情习惯（哪个场景用哪个）/ 句子长短 / 回复节奏（秒回·看心情·晾）
3. **情感表达**：在乎怎么表现 / 不满怎么表现 / 什么时候说软话
4. **冲突链**：触发点 → 第一反应（炸还是缩）→ 冷战多久 → 谁先开口
5. **关系角色**：她是主动方还是被追方 / 主动联系的触发场景 / 消失前预兆
6. **投入度 0~100**，依据：她主动开场占比、她/我字数比、她提问次数、有没有用「我们/以后/一起」、拒绝是硬拒还是留口子

## 必须回答
① 她下一步最可能怎么反应（2~3 种，标概率）② 她现在最吃哪一套（被读懂 / 被逗 / 被需要 / 被带着走 / 被晾一下）③ 这一轮该推进一格、稳一稳，还是后撤半步

## 硬规矩
只用她原话当证据；不足就写「样本不足」；不许把「她没回」直接定性为不喜欢；行为与标签冲突时以行为为准。
⚠️ 与技能③启发式1的关系（别混）：「她没回」= **零样本**，不能定性 → 这时该**再推一次**（换角度、给点她想要的）；
「她回了但读不懂」= **有样本但模糊**，按「目前没投入」处理（别在模糊信号上加注）。两者判据不同，不矛盾。
